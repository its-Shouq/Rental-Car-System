# Wheels - Car Rental System 🚗

Wheels is a simple car rental application built with Python and
Streamlit.

The system allows customers to create an account, log in, browse
available cars, filter cars, manage their booking, and confirm a rental.
It also provides an admin interface for managing the available cars.

## Features
-   Welcome page with navigation to login and registration
-   Customer and admin authentication
-   Browse available rental cars
-   View car details including model, year, color, price, and
    availability
-   Filter cars by color and year
-   Sort cars by price
-   Select rental dates
-   Modify or remove a booking
-   Checkout and view a rental receipt
-   Admin dashboard for fleet management
-   Add new cars to the fleet
-   Update car price and quantity
-   Delete cars from the fleet
-   Responsive user interface

## Technologies Used
